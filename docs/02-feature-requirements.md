# Yuki 功能需求

以下按管理员和普通用户的使用场景列出功能需求。

## 管理端

| 功能 | 需求 |
| --- | --- |
| 曲库维护 | 管理员维护平台自有曲库及音乐资料 |
| 文件上传 | 上传音频和封面 |
| 管理权限 | 使用固定管理员权限控制管理功能的访问 |
| 音频处理 | 支持常见音频格式，识别时长等基础信息，生成统一播放资源并展示处理结果 |

## 用户端

| 功能 | 需求 |
| --- | --- |
| 音乐播放 | 使用平台统一维护的曲库播放音乐 |
| 个人收藏 | 支持个人音乐收藏 |
| 歌单 | 提供歌单能力 |
| 播放记录 | 记录用户的音乐播放历史 |
