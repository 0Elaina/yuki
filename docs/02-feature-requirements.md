# 功能需求

## 产品与使用者

Yuki 面向个人自托管使用，提供以娱乐、角色互动与陪伴为重点的 Live2D AI 聊天体验。一个部署服务一个使用者，各设备共用该部署的角色、会话、资源和设置。

项目只有一个前端，统一提供聊天与配置入口，没有登录、注册、用户角色和权限体系。默认在个人可信访问环境使用，应用访问者具有该部署的数据和配置操作能力，不提供不同访问者之间的数据隔离。

## 角色与陪伴体验

| 能力 | 已确认要求 |
| --- | --- |
| 多角色配置 | 能够维护多个角色并选择一个角色进行对话，以单角色对话为主要使用方式 |
| 人设配置 | 能够维护角色的身份、性格和背景设定，使模型回答围绕所选角色组织 |
| 角色资源关联 | 能够将角色与 Live2D 资源、语音配置和背景资料关联 |
| Live2D 表现 | 在 Web 中展示角色形象，结合聊天和语音提供角色表现；具体表情、动作与口型能力按模型和运行时支持情况确定 |
| 互动连续性 | 角色能够参考当前会话和此前保留的互动信息 |

## 文字、语音与会话

| 能力 | 已确认要求 |
| --- | --- |
| 文字聊天 | 用户能够发送文字并查看所选角色的回复，等待、完成与失败均有清晰反馈 |
| 语音输入 | 支持将用户语音交由独立语音识别服务转换为可用于对话的文字 |
| 语音输出 | 支持使用独立语音合成服务生成角色语音，并在 Web 中播放 |
| 会话与消息记录 | 保存会话及消息记录，供用户查看历史和继续对话 |
| 文字与角色表现配合 | 回复文本、播放音频与 Live2D 表现归属于当前角色及对话，避免切换后继续显示或播放旧角色结果 |
| 操作反馈 | 对模型调用、录音、资源加载和音频播放提供明确反馈，能够判断操作是否成功 |

## 长期记忆与背景资料

| 能力 | 已确认要求 |
| --- | --- |
| 跨会话长期记忆 | 角色能够参考以往互动中保留的信息，默认按角色隔离记忆范围 |
| 记忆来源 | 记忆与其产生依据保持可管理的关联，不把模型生成内容自动视为可靠事实 |
| 角色背景与世界观资料 | 独立维护用于角色回应的背景资料，允许多个角色引用同一资料 |
| 语义检索 | 根据当前对话查询相关记忆和资料，并限制检索范围，避免混用其他角色的独立记忆 |

## 资源与应用设置

| 能力 | 已确认要求 |
| --- | --- |
| 资源维护 | 在同一个前端维护角色所需的 Live2D、音频等资源 |
| 模型服务配置 | 在 Web 中维护 LLM、Embedding、语音识别和语音合成服务所需的连接信息与应用参数 |
| 服务密钥维护 | 在 Web 中录入或更换服务密钥，由服务端加密保存；读取配置时只返回配置状态与掩码 |
| 本地与云端服务 | 支持选择本地部署或云端模型服务 |
| 配置归属 | 应用设置在 Web 内维护，数据库等基础设施连接与加密主密钥由服务端部署配置提供 |
